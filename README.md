# Linguagem C e Estrutura de Dados

Repositório criado para registrar meus estudos e minha evolução na linguagem C, desde os fundamentos da programação até os primeiros conceitos de Estrutura de Dados.

Aqui estão reunidos exercícios, testes e pequenos programas desenvolvidos durante meus estudos de Ciência da Computação.

## Sobre o repositório

Este repositório funciona como um histórico prático do meu aprendizado em C.

Os programas foram desenvolvidos para praticar conceitos fundamentais da linguagem, lógica de programação, manipulação de strings, estruturas de decisão, estruturas de repetição, funções e estruturas de dados.

A ideia é manter neste repositório tanto exercícios simples quanto implementações que representem minha evolução ao longo do aprendizado.
